# Pak German Academy — 2026 Dark-Mode Creative Agency React App

## Quick Start (Vite Local Runner)

### Option A: Direct Project Run
```bash
npm install
npm run dev
```

### Option B: Single-Script Node Scaffolder (`setup.mjs`)
If you move `setup.mjs` into any empty directory, run:
```bash
node setup.mjs
npm install
npm run dev
```

## Included Files
- `src/App.jsx`: Complete single-page React application with scroll-linked spring animations, WebGL-inspired interactive aurora/constellation canvas, interactive German audio pronunciation lab (`de-DE`), A1–B2 Course Grid, CEFR Level Diagnostic Quiz, Hybrid Pro & Online Split Learning Modes, Visa Consultancy Services (Study, Ausbildung, Family Reunion) with interactive milestone tracker, and Gujranwala campus footer.
- `src/index.css`: Tailwind CSS setup + glassmorphism & German-flag glowing gradient utilities.
- `setup.mjs`: Self-contained Node setup script that generates all project files automatically.
